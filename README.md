
# Sistem Manajemen Waktu dan Tugas Siswa (SMWTS)

## Deskripsi
SMWTS merupakan sistem berbasis web yang dirancang untuk membantu siswa mengatur dan mengelola tugas sekolah. Sistem ini juga memudahkan guru dalam memberikan tugas dan memantau perkembangan pengerjaan tugas siswa.

## Fitur Utama
1. Login dan pengelolaan akun
2. Daftar tugas (To-Do List)
3. Kalender tugas berdasarkan deadline
4. Pengingat tugas satu hari sebelum deadline
5. Pengaturan status pengerjaan tugas
6. Pengelolaan dan pemantauan tugas oleh guru

## Teknologi yang Digunakan
1. PHP
2. MySQL
3. HTML
4. CSS

## Metode Pengembangan
Sistem dikembangkan menggunakan metode Agile melalui proses perencanaan, perancangan, pengembangan, pengujian, dan evaluasi.
